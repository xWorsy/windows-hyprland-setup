# Windows как Hyprland

Сборка, которая делает Windows 11 похожей на Linux с Hyprland: окна сами встают плитками, всем управляешь
клавиатурой (не трогая мышь), сверху красивая панель, терминал полупрозрачный.

Что внутри:

- **GlazeWM**: менеджер окон (окна плитками, хоткеи, рабочие столы 1–9, рамка вокруг активного окна).
- **Zebar**: верхняя панель (рабочие столы, время, сеть, память, процессор, погода) в зелёных цветах. Своя тема `night-arch`.
- **Оформление Windows Terminal**: прозрачность 65% с размытием, тёмная цветовая схема, шрифт Cascadia Code.
- **Необязательно**: спрятать нижнюю панель задач Windows (обходной способ, может глючить).

> Сборка проверена только на одном компьютере (Windows 11 Pro 25H2, монитор 2560×1440). На других экранах,
> версиях Windows и с другими программами мелочи могут отличаться.

## Что нужно

- Windows 11 (на Windows 10 не проверялось; скруглённые углы окон работают только на 11).
- Установленный `winget` («Установщик приложений» из Microsoft Store; в Windows 11 он есть сразу).
- Для хоткея `Alt+B` (браузер): Google Chrome. Если Chrome другой или его нет, этот хоткей просто не сработает
  (поменять можно в `%USERPROFILE%\.glzr\glazewm\config.yaml`, строка `alt+b`).

## Установка

1. Скачай репозиторий: зелёная кнопка **Code → Download ZIP**, распакуй в любую папку
   (или `git clone https://github.com/xWorsy/windows-hyprland-setup.git`).
2. Открой в этой папке PowerShell (в проводнике: правая кнопка → «Открыть в Терминале»).
3. Выполни:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```

4. Скрипт задаст пару вопросов (запускать GlazeWM при входе в Windows? прятать панель задач?), потом:
   поставит GlazeWM и Zebar (появится окно «Разрешить внесение изменений», нажми «Да»), скопирует настройки,
   оформит терминал и запустит GlazeWM. Окна сразу перестроятся плитками, это нормально.

Ничего не удаляется: старые настройки скрипт сохраняет копиями (папка `.glzr.backup-…` в профиле и файл
`settings.backup-before-night-arch.json` рядом с настройками терминала).

Если скрипт не запускается с ошибкой про «выполнение скриптов отключено» или «файл заблокирован»,
сначала выполни `Get-ChildItem -Recurse | Unblock-File` в папке репозитория.

## Хоткеи

Главная клавиша **Alt** (не Win: Windows сама перехватывает многие сочетания с Win).

| Сочетание | Что делает |
|---|---|
| `Alt + Enter` | открыть терминал |
| `Alt + B` / `Alt + E` | открыть Chrome / Проводник |
| `Alt + Q` | закрыть окно |
| `Alt + h/j/k/l` или `Alt + стрелки` | перейти на соседнее окно (влево, вниз, вверх, вправо) |
| `Alt + Shift + h/j/k/l` или `Alt + Shift + стрелки` | переставить окно в эту сторону |
| `Alt + 1…9` | перейти на рабочий стол |
| `Alt + Shift + 1…9` | унести окно на другой рабочий стол |
| `Alt + A` / `Alt + S` / `Alt + D` | предыдущий / следующий / последний рабочий стол |
| `Alt + F` | окно на весь экран |
| `Alt + Shift + Space` | сделать окно плавающим (и обратно) |
| `Alt + T` | вернуть плавающее окно в плитки |
| `Alt + V` | куда встанет следующее окно: справа или снизу |
| `Alt + R` | режим изменения размера: стрелки или h/j/k/l, выйти: `Alt + R`, `Esc` или `Enter` |
| `Alt + U/I/O/P` | менять размер окна без режима |
| `Alt + M` | свернуть окно |
| `Alt + Space` | переключить фокус между плиточными и плавающими окнами |
| `Alt + Shift + P` | поставить GlazeWM на паузу (удобно в играх) / снять паузу |
| `Alt + Shift + R` | перечитать настройки |
| `Alt + Shift + E` | выйти из GlazeWM (окна останутся как есть) |

Слева на верхней панели кнопка с логотипом Windows открывает меню «Пуск» (повторное нажатие закрывает).
Все хоткеи лежат в `%USERPROFILE%\.glzr\glazewm\config.yaml`, их можно менять.

## Что сборка меняет на компьютере

- Ставит программы GlazeWM и Zebar (через winget).
- Создаёт папку `%USERPROFILE%\.glzr` (настройки и скрипты).
- Меняет настройки Windows Terminal (прозрачность, цвета, шрифт), копия старых сохраняется.
- По вопросам при установке: записи автозапуска в реестре (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`,
  имена `GlazeWM` и `TaskbarHide`, только для твоей учётной записи).

Системные файлы Windows и защитные настройки не трогаются. Права администратора нужны только установщику GlazeWM.

## Спрятать панель задач (необязательно)

Это обходной способ, а не настройка Windows: фоновый скрипт каждые 0,15 секунды прячет окно панели задач.
Минусы: пропадают значки в углу (трей, звук, раскладка), панель может на долю секунды мелькнуть, «Пуск» без неё
иногда ведёт себя странно. Не понравилось, запусти `uninstall.ps1` (он вернёт панель) или только:

```powershell
powershell -NoProfile -File "$env:USERPROFILE\.glzr\taskbar.ps1" show
```

## Обои

Обои в репозиторий не входят. Поставь любые; панель сделана в зелёных тонах (светло-зелёный, тёмно-зелёный, золото),
цвета лежат в `%USERPROFILE%\.glzr\zebar\night-arch\styles.css` (переменные в начале файла) и меняются за минуту.
Рамка активного окна: `window_effects` в `config.yaml`.

## Удаление

```powershell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1
```

Скрипт по шагам, с вопросами: остановит GlazeWM и Zebar, вернёт панель задач, уберёт автозапуск, вернёт твои
прежние настройки GlazeWM и терминала, а на вопрос «удалить программы?» удалит GlazeWM и Zebar.
Свои файлы он не стирает, а переименовывает (`.glzr.removed-…`), окончательно удалить копии можно, только
ответив «да» на последний вопрос. Если GlazeWM уже не нужен, достаточно `winget uninstall --id glzr-io.glazewm`
(и Zebar, если остался в списке программ).

## Если что-то не работает

- **Окна ведут себя странно**: `Alt + Shift + P` ставит GlazeWM на паузу. Игры и программы, которые сами
  управляют размером окна, лучше добавить в исключения: блок `window_rules` в `config.yaml`.
- **Нет верхней панели**: открой журнал `%USERPROFILE%\.glzr\zebar\errors.log`. Панели нужен интернет: значки и
  библиотека React подгружаются из сети при каждом запуске, без интернета панель пустая или не появится.
- **Кнопка «Пуск» на панели не работает**: если в имени пользователя Windows есть пробелы или не латинские
  буквы, а короткие (8.3) имена на диске отключены, GlazeWM не может запустить скрипт. Установщик в этом случае
  предупредит.
- **Проблемы с прозрачностью терминала**: в `settings.json` терминала строка `"opacity": 65`
  (меньше число = прозрачнее).
